# 下書きのサンプル

これは下書きのサンプルです。プレビューでは、タイトルの上に「DRAFT」のバッジが付いて表示されます。本番のサイトには出力されません。

## 書き方

下書きでも、公開するページと同じ書き方が使えます。

!!! note "メモ"

    Admonition やコードブロックなど、[執筆](../guides/writing.md)で紹介している記法も同じように表示されます。

```yaml
---
title: 任意のページタイトル
---
```

書き終えたら、[下書きの README](README.md) の「下書きを公開する」の手順で公開します。
