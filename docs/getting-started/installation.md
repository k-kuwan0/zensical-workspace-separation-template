# インストール

## 前提

- Docker Desktop / OrbStack など Docker Compose 対応環境
- VSCode（推奨）

## セットアップ

1. リポジトリをクローンする
2. VSCode でリポジトリを開く
3. `Cmd+Shift+P` → `Tasks: Run Task` → **コンテナビルド** を実行（初回のみ）
4. 同様に **コンテナ起動** を実行
5. **プレビュー起動** を実行し、ブラウザで `http://localhost:8001` を開く

以上でローカルプレビューが立ち上がります。
